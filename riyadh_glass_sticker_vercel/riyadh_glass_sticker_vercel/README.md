# زجاج الرياض برو — موقع خدمات الزجاج والاستيكرات في الرياض

مشروع Static HTML/CSS/JS جاهز للرفع على Vercel.

## يحتوي على
- صفحات خدمات مستقلة داخل /services/
- صفحات أحياء ومناطق الرياض داخل /areas/
- صفحات الثقة: /about/ و /contact/ و /privacy/ و /terms/
- ملفات SEO: sitemap.xml, robots.txt, llms.txt
- Schema: LocalBusiness, Service, FAQ, Breadcrumb
- صور Placeholder قبل/بعد داخل assets/images/work

## خطوات الرفع على Vercel
1. فك الضغط عن الملف.
2. ارفع المجلد إلى GitHub.
3. افتح Vercel واختر New Project.
4. اربط مستودع GitHub.
5. لا تحتاج Build Command لأن الموقع Static.
6. بعد النشر، غيّر الدومين في كل الملفات من https://riyadh-glass-stickers.vercel.app إلى دومينك الحقيقي.
7. ارفع sitemap.xml في Google Search Console و Bing Webmaster Tools.

## مهم
الصور الموجودة بديلة وليست صور أعمال حقيقية. استبدلها بصورك داخل assets/images/work/.
